## Remaining source-edit interface limitation

The model still has to copy exact old source through JSON. The real1.5B failure shows why that is fragile; do not silently unescape or repair rejected code to manufacture a proposal. Next bounded design: expose server-owned structured excerpt offsets, let the model select visible line IDs and provide replacement/checks, resolve old bytes and identities on the server, then reuse all current uniqueness/visibility/blob/syntax/bounds gates. Never recover offsets by parsing model-visible Markdown labels. Ranges must remain inside one visible interval with no omitted gaps. The existing excerpt renderer also substitutes triple backticks while claiming exact source; this currently fails closed for affected anchors and should use unchanged source with longer fences in that future refactor. This design is NOT IMPLEMENTED, does not fix semantic reasoning or7B abstention, and requires fresh independent evaluation before promotion.
