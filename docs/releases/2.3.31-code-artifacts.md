## Purpose

Turn assistant code responses into a first-class Chat artifact instead of leaving fenced code and its explanation as unrelated visual fragments.

## Behavior

- Any assistant response containing rendered code blocks is upgraded into one outer **Code artifact** container.
- The outer artifact owns the response's code workspace plus the explanatory material associated with that code.
- Introductory text before the first code block remains inside the artifact as lead-in content.
- Explanation/details after the code remain inside the same artifact under a **Details** section.
- Multiple code blocks in one response become file tabs inside a single code project container.
- Common languages receive useful default filenames such as `main.cpp`, `main.py`, `index.html`, `styles.css`, and `script.js`; explicit filenames near a code block are preferred when present.
- Each file tab has **Copy** and **Download** controls.
- The artifact has **Copy all** and **Export all** controls. Export all currently produces a structured `swrlz-code-artifact-v1` JSON bundle containing every filename, language, and file body.
- Large code bodies grow to a bounded height and then scroll internally, keeping the main conversation compact.
- The feature is implemented as runtime-owned Chat JavaScript/CSS and is injected by `runtime_pages/manifest.json`.
