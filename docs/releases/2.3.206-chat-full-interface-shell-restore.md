# Server 2.3.206 / Chat 1.5.56 — full Chat interface shell restoration

## Root cause corrected
During the Android boot investigation, commit `7c66b250c3b325b0b83d4b5c02d435c4f00420e7` was intended to add an inline pre-runtime probe to `web/chat.html`, but its diff also removed/replaced a very large portion of the canonical Chat HTML/CSS/JS shell. The file fell from 62,365 bytes (`046fb854...`) to 38,569 bytes (`0b6458d8...`). That unintentionally converted the visible Chat toward the plain/base interface seen in the regression screenshots.

## Repair
Restore `web/chat.html` exactly to its immediate pre-probe blob `046fb854c851b8bc97158dd000a6c073c7934e63` while preserving every other newer runtime/main change. This restores the complete interface shell rather than trying to recreate the missing UI piecemeal.

The external `chat_debug_log_v1.js` and loader/server telemetry remain available. The destructive inline probe is removed with the bad shell replacement.
