# Qwen coder learning tracks — source index

This directory contains open teaching curricula and reference/fixture material for the §C coder/planner student. They do not alter live model weights or automatically inject prompts into the hosted coder.

- [Project Stack & Architecture v1](PROJECT_STACK_ARCHITECTURE_V1.md): source-grounded code ownership, actual language/runtime boundaries, build and deployment reasoning.
- [Cross-language Curriculum v2](CROSS_LANGUAGE_CURRICULUM_V2.md): transfers and explicit toolchain checks; educational, not an installed rewrite.
- [§E Model Atelier Academy v1](../forge-modeling/README.md): how to understand and plan native 3D editing, actor versus mesh ownership, component/sculpt workflows, geometry/anatomy, safe editor proposals, asset export and rigging limits. Its [36 public scenarios](../forge-modeling/academy_v1.json) include both allowed operations and unsupported-operation traps; use the [offline validator](../forge-modeling/verify_academy.py) to verify source anchors, **not** coder skill.
- [Model maturity discovery v4](MODEL_MATURITY_DISCOVERY_V4.md) and [maturity effort v3](MODEL_MATURITY_EFFORT_V3.md): staged assessment and effort contracts.

**Model execution, hidden held-out evaluation, and promotion:** Never equate presence of teaching files with actual learning. Record student outputs, independent pass/fail evidence and provenance separately. For live Forge actions keep the existing verified-account, active-host and receipt/approval path. No teaching file grants tools, engine deployment, secrets or arbitrary code execution.
