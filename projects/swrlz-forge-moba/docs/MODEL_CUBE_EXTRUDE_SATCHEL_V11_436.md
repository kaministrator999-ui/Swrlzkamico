# §E v11.436 — Cube Extrude and connected Satchel topology

The VR Extrude button previously targeted drawn-outline faces, not the original solid box. The new scoped action uses the existing native manual mesh bridge only for selected boxes/topology parts; it converts a plain box with native Undo, requests a real face Trigger selection and exposes Preview/Apply. Nonbox drawn-outline Extrude remains unchanged. No invisible automatic extrude or parallel editor was added.

The prior Satchel tutorial demanded four thin wall cubes and a floor slab, even after the native topology workshop became available. Its current Step 2 now requires one converted cube, face Inset, and inward Extrude. The existing Show Me navigation, real button references, VR ghost and checklist verify these actual operations. The ghost is one connected topology mesh. The checker inspects upward-facing recessed inner cap triangles and walls reaching the original top rim. Legacy five-box tutorials still validate and retain saved progress.
