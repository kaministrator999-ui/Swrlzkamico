## Captured spirit behavior

The existing native capture path creates a wisp and records its personal home inside the pen. Wisp movement uses ordinary finite native move orders, at 0.35 m/s rather than the previous 3.5 m/s. Move targets are no longer clamped inside the pen. Each update permits drift up to 2.5 m outside the pen's existing X/Z half-extents; crossing any side returns the spirit to its recorded home, clears the move order and partial rescue timers, and retains the captured state. The current player receives a return message. Diagnostic status exposes actual speed, leash margin, home and return count. A captured wisp cannot build or revive itself; only the existing living-sheep approach/hold rescue turns it back into a sheep and applies the normal protection window. The rules work on older native maps too, using their actual pen center and dimensions.

## Large-map navigation

Large-map rules accept bounds up to 160 m, supporting the default ±128 m scene without silently clamping it. On maps above the old size limit, native path queries first return a straight path when continuous collision checks allow it. Obstructed trips try fine 0.15 m local grids, translating all circular/rotated rectangular obstacles and their corners into a snapped local frame. Boundary slabs prevent routing outside the true world. Up to three grids are cached by navigation version, species radius and search window; construction invalidation clears them. A wider window and then the original full-world search preserve detours that leave a local window. Returned points are world-space, and the existing continuous collision checks still validate every movement step. Smaller maps retain their previous navigation path.
