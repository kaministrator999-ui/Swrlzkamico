# Organic sheep and wolf starters

The owner requested a new sheep model project and more natural sheep/wolf starter models, avoiding visible primitive blockouts. Clover and Fen use explicit indexed organic meshes generated with the native volume tool. The large body is one connected, closed, welded surface formed by smoothly blended anatomical fields. Construction volumes are resampled away; they are not separate renderable primitive parts. Separate editable facial, ear, foot and tail meshes carry smaller details. The wolf has a quadruped silhouette, shoulder mass, tucked waist, long nasal bridge, short ears, deep-set eyes, hocks, four toes/claws per paw and a low curved tail. The sheep has a wool-covered trunk/upper legs, bare tapered face, folded ears, horizontal pupils and cloven hooves.

The atlas contains directional fibers, wool curls, leather and iris regions at 4096×4096 with a corresponding tangent normal map. Surface geometry adds restrained wool relief; color/normal detail stays shared across parts. Vertex dye places dark dorsal fur and pale throat/belly on the wolf. Native textured GLB export includes actual images and UVs and supports mixing legacy and new atlases. Existing game visuals and authored map data are preserved; these independent models are reached through their model project cards and stable `sheep-model` / `wolf-model` query links.

Targeted checks validate every authored index/coordinate/UV, part/group limits, one connected closed main body, real 4K image dimensions, exact packaged scene bytes and preservation of all 277 preceding sources and 51 preceding assets. Chromium opens both starters, runs the native organic tool inside the editor to reproduce the bundled model, edits and undoes a material setting, saves/reimports the detailed native model, and exports a portable textured GLB. GLB checks inspect actual mesh/index/normal/UV/image data. Device acceptance follows confirmed deployment. These remain editable static model starters; skeletal weight painting and production animation rigs are separate work.

Final close-up polish softens default fiber normal strength (wolf body 0.12; generic small surfaces 0.16). Wool retains its explicit 0.32 setting. The complete in-editor build/edit/undo/save/reimport/export checks passed before this defaults-only adjustment; final native tool regeneration proves the updated defaults and every geometry/UV value match the authored payload. A final targeted Chromium pass checks the softened surfaces and real embedded GLB export at desktop and phone sizes. Geometry and image bytes are preserved across this final shading refinement.

Initial studio framing waits for two browser layout frames, so the fit uses the final phone viewport aspect rather than the pre-studio inspector layout. The final surface test opens each model directly at phone dimensions before checking the desktop view and export.
