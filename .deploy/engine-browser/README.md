# OVH server Chromium QA
Reuses /usr/bin/chromium and /srv/swrlz/browser-venv/bin/python. The existing restricted SSH gate adds two fixed actions, live and candidate. Browser runs as swrlz-deploy with Chromium sandbox enabled; no new sudo grants, no browser install, no external port, no production writes. The test uses the real server document tree (or staged allowlisted overlay) in an isolated OVH-origin browser; this does not verify authenticated HTTP delivery. SSH returns a bounded ZIP with screenshot bytes and hashes; GitHub only relays artifacts. The existing runtime release workflow is unchanged until this new lane passes. Install using the pinned root-owned helper after review; then run the OVH §E server Chromium QA workflow. No credentials are passed into browser page content. Candidate QA is restricted to the current runtime and humanoid overlay files.
